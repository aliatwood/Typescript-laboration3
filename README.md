# Laboration 3 - Angular

## Beskrivning
Detta projekt är en webbapplikation byggd med Angular. Webbplatsen innehåller flera undersidor och använder Angular Router för navigering mellan sidorna.

Projektet har utvecklats för att lära sig grunderna i Angular, inklusive komponenter, databindning och routing i en Single Page Application (SPA).

Webbplatsen innehåller även en konverteringssida där användaren kan omvandla värden mellan:
- Meter och feet
- Celsius och Fahrenheit

Utöver detta finns en informationssida som beskriver projektets syfte och reflektioner kring utvecklingsprocessen.

## Funktioner
- Navigationsmeny med Angular Router
- Minst tre undersidor (Startsida, Konverterare, Om projektet)
- En konverterare byggd med Angular komponenter och databindning
- En bild på startsidan
- Responsiv design med CSS
- Footer och grundläggande layoutstruktur

## Installation
```bash
git clone https://github.com/aliatwood/Typescript-laboration3.git
cd Typescript-laboration3
npm install
ng serve
```
